# 影像量测条目复核底图（z18）使用说明

> 生成：`python 06_代码/fetch_z18_measured.py`（2026-11-01）
> 数据源：高德 z18 卫星瓦片（GCJ-02，已按 `wgs2gcj` 配准），0.46 m/px
> 本目录每栋一张 `<key>_z18_grid.jpg`：10 m 网格、青色框 = 现行 bbox、网格原点 = 该栋 `measured.lat/lon`

## 为什么需要人工复核

11 个 `src=measured` 条目只有「矩形 bbox 代理轮廓 + 面积字段」，其中：

- C03 大食堂、C04 浴池的 bbox 是面积字段的 1.9~2.6 倍（画出来过大）；
- X01 信息学院的 `area_m2` 原来几乎等于 bbox 面积（5,572 ≈ 5,513），已按本目录描线修正为 **3,718.5 m²**（2026-11-01，正式数据已更新）。

2026-11-01 试过两种自动重算，都不可靠：

1. **高德路网图建筑填充色**：白边、注记、相邻楼会把填充切断——信息学院只量到 1,402 m²（修正前 5,572）、大食堂 5,205（现值 9,600）、材料A·亚稳 24 m²，不能用。
2. **z18 卫星暗屋顶阈值**：会把门前铺装/阴影一起算进去（信息学院红 mask 覆盖了广场），也不能用。

所以**其余 10 项保留原面积**，把 z18 底图准备好，由人按网格描屋顶；X01 已按此流程完成。

## 怎么描（每栋 5~10 分钟）

1. 打开 `<key>_z18_grid.jpg`，网格每格 10 m，原点 (0,0) 是该栋中心；青框是现行 bbox。
2. 沿屋顶外缘读点，记录 `(x, y)` 米（相对原点，东正北正）；弧形楼取 12~20 个点即可。
3. 用鞋带公式算面积：

   ```python
   area = abs(sum(x[i]*y[i+1] - x[i+1]*y[i] for i in range(n))) / 2
   ```

4. 把结果写回 `06_代码/groups.py` 对应条目的 `measured=dict(area_m2=...)`；如果同时要收紧 bbox，改 `bbox=[minLon,minLat,maxLon,maxLat]`（用网格读数换算：`lon = lon0 + x/85387`，`lat = lat0 + y/111320`）。
5. 重跑：

   ```bash
   python 06_代码/build_bundle_v2.py
   python 06_代码/add_service_points.py
   python 06_代码/viz_25d.py
   ```

   然后同步 `00_README.md`、字段字典、`03_实施方案` 与验收脚本里的数字。
